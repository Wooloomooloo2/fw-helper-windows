BIOS 03.02 vs 03.04: power, frame rate and power modes

A summary of the A/B game runs in docs/hardware-baseline.md. A is BIOS 03.02 with EC sakura-3.0.2; B is BIOS 03.04 with EC sakura-3.0.4. The Intel DTT drivers were the same for both, so the differences come from the firmware. Three games, each run in Balanced and Performance, with the EC fan unless marked.

1 · Power

CPU and GPU watts inside the package

CPU cores GPU Rest of package (uncore, memory, I/O) 03.04 DTT PL1 for that mode
  • 03.02 left power unused. The package drew 22–28 W in either mode while the GPU sat at 1850 MHz, held by the PL4 current limit in 90–99% of samples. Balanced and Performance drew the same power, except in Cyberpunk.
  • 03.04 fills the budget DTT sets. The package runs at 24.3–24.9 W in Balanced (PL1 25 W) and 29.8–31.5 W in Performance (PL1 30–33 W). The CPU and GPU share that budget.
  • The extra watts go where the game needs them. Cyberpunk, which is GPU-bound, gives them to the GPU: +2.6 W and 2000 MHz, while the CPU drops 1.2 W. Horizon Zero Dawn gives them to the CPU, which goes from 7.5 to 14.8 W; GPU watts stay flat and its clock falls from 1850 to 1550 MHz. That game was CPU-starved on 03.02, at about 1.7 GHz and 7 W. Tomb Raider in Performance raises both.
  • The rest of the package stays at 5–6 W, except Tomb Raider Performance on 03.04 at 2.4 W, which is worth re-checking.

3 · Power modes

What Performance adds over Balanced

03.02 03.04
Game03.02 FPS · package W03.04 FPS · package W03.04 FPS per W, Bal / Perf
  • On 03.02, Performance changed median FPS by −2% to +2%: noise. The GPU hit the same current limit in both modes.
  • On 03.04, Performance adds 8–12% for 5–7 W more package power, because DTT raises PL1 from 25 W to 30–33 W and that is now the limit.
  • Balanced on 03.04 gives the most frames per watt in all three games, and it beats Performance on 03.02 in all three at the same or lower power.
4 · Conclusions

What changed and what it means

  1. 03.04 moves the bottleneck from current to power. On 03.02 the GPU stopped at a PL4 current limit near 1850 MHz with package power to spare. On 03.04 PL4 never binds, and every run is held by the DTT PL1 budget. The firmware diff points to DTT: its four EC sensors now report every second (_TSP 0 → 10) where 03.02 never polled them. That DTT then ran in a conservative state is a hypothesis, not yet verified.
  2. The update is a straight gain for gaming. Median FPS is up 9–21% in every game and mode with the EC fan, and the 5th percentile is up in every run that can be compared.
  3. The Windows power mode now matters. Performance is worth about 10% in these games. Balanced on 03.04 is the efficiency choice and still beats anything 03.02 could do.
  4. The CPU/GPU split depends on the game, and the app can't tune it in Performance yet. In CPU-heavy games the CPU now takes watts from the GPU. Without admin rights, the Best Performance overlay ignores frequency caps, so nothing between about 1.8 and 4.5 GHz can be set to shift that budget.
  5. Cooling may buy a little more. ITMT3 scales PL1 between 30 and 33 W with the SEN2 temperature. The custom-fan run held 31.5 W against 29.9 W with the EC fan, which fits that.

Still open

  • Run Tomb Raider in Performance with the EC fan to separate the fan's share of the +31%.
  • Repeat Cyberpunk Balanced on 03.04 at full length to get a usable 5th percentile.
  • Find SEN2 (VCCGT): none of the EC's own sensors sits near the new 59 °C trip in Performance runs.
  • Check the 2.4 W rest-of-package reading in the Tomb Raider Performance run.
